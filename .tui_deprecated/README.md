# Archived terminal monitor

Source snapshot of Controls’ Bubble Tea monitor before its extraction on 2026-11-01.

`dashboard/` contains the complete implementation and tests, including the old logs view. `internal/cli/cli.go`, `go.mod` and `go.sum` preserve the entrypoint and dependency context. Preview images are retained here.

This is a historical source archive, not a supported standalone Go module: it imports Controls internal packages. The supported monitor is the Svelte application at the repository root. Do not add new UI code here.
